# Fun coding agent GUI core

UniFFI crate for the macOS and iOS windows. Agent, tools, sessions, and Grok login live here. Swift only renders.

Checkout next to the apps:

```
~/fun-coding-agent-gui-core
~/fun-coding-agent-macos
~/fun-coding-agent-ios
```

Xcode builds this crate (`scripts/build.sh`) into each app’s `Fun/Generated/`.
